CS50 Problem Sets
This repository contains my completed problem sets from CS50, Harvard's introductory course in Computer Science.
The focus is on building strong foundations through hands-on implementation — not tutorials or copy-paste solutions.
Scope
Problem sets organized by week, covering:

C programming (pointers, arrays, strings, structs)
Manual memory management (malloc, free, pointer arithmetic)
Data structures (linked lists, hash tables, tries)
File I/O and binary data manipulation
Debugging and reasoning about program behavior at the systems level

Technologies

C
CS50 Library
GCC / Clang
Command-line tools

Notes
This repository documents foundational work in computer science fundamentals — disciplined practice that supports deeper software engineering and systems development.
